NEON SNAKE — ГОТОВОЕ МОБИЛЬНОЕ PWA-ПРИЛОЖЕНИЕ
===============================================

В комплекте:
- index.html — игра NEON SNAKE;
- manifest.json — параметры установки приложения;
- sw.js — офлайн-кеширование после первого запуска;
- icon-192.png и icon-512.png — иконки;
- .github/workflows/deploy.yml — автоматическая публикация через GitHub Pages.

Игра:
- поле 20 × 20;
- свайпы, экранные кнопки, стрелки и WASD;
- проход сквозь стены;
- яблоки, рост змейки, счёт и локальный рекорд;
- пауза и звуковые эффекты;
- экран победы при заполнении всех 400 клеток;
- адаптация под экран телефона.

КАК ОПУБЛИКОВАТЬ И УСТАНОВИТЬ
-----------------------------
1. Распакуйте архив на компьютере.
2. Создайте репозиторий на https://github.com/ (например, neon-snake).
3. Загрузите ВСЁ содержимое этой папки в корень репозитория, включая папку .github.
4. В GitHub откройте Settings → Pages.
5. В разделе Build and deployment выберите GitHub Actions.
6. Откройте вкладку Actions и дождитесь завершения Deploy NEON SNAKE PWA.
7. Откройте опубликованный адрес вида https://ВАШ-ЛОГИН.github.io/neon-snake/.

Установка на iPhone:
1. Откройте опубликованный HTTPS-адрес в Safari.
2. Нажмите «Поделиться» → «На экран Домой».
3. Если доступен переключатель «Открывать как веб-приложение», включите его.
4. Нажмите «Добавить». Игра появится на главном экране.

Установка на Android:
1. Откройте HTTPS-адрес в Chrome.
2. Нажмите меню ⋮ → «Установить приложение» или «Добавить на главный экран».
3. Подтвердите установку.

ВАЖНО
-----
Это устанавливаемое веб-приложение (PWA): оно запускается с иконки почти как обычное приложение и поддерживает офлайн-режим после первой загрузки. Для установки нужен опубликованный HTTPS-адрес. Сам архив не является подписанным файлом IPA/APK и не публикует приложение в App Store или Google Play. Для нативной публикации потребуются отдельная сборка и аккаунты разработчика.
